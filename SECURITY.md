# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, use GitHub's private vulnerability reporting for this repository when available. Include a concise description, affected version or commit, reproduction steps, and any known impact.

For ordinary correctness bugs, numerical issues, or documentation problems, use the public issue tracker.

## Supported versions

Until the first stable release, security and correctness fixes are applied to the current development line only.
