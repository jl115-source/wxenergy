wxenergy
========

Weather and climate utilities for energy analysis.

``wxenergy`` provides small, composable functions for common weather and climate
processing tasks built around xarray. The package is intentionally narrow: it
focuses on reusable data-processing infrastructure rather than forecasting or
trading logic.

Development status
------------------

``wxenergy`` is under active development. The current development series is
``0.2.x`` and the public API may still change before a stable ``1.0`` release.
