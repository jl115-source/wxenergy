wxenergy: weather and climate utilities for energy analysis

A small Python package for preparing, transforming, and aggregating weather and climate data with xarray.

Development status wxenergy is under active development. The first packaged release is planned for v0.1. 
import xarray as xr
import wxenergy as wx

ds = xr.open_dataset("temperature.nc")
ds = wx.standardize(ds)

anom = wx.anomaly(ds.t2m, climatology="dayofyear")
hdd = wx.hdd(ds.t2m, base=18)

Key features

  • xarray-native — work directly with DataArray and Dataset objects.
  • Standardization — common coordinate, longitude, time, unit, and metadata handling.
  • Climate statistics — climatologies, anomalies, percentiles, and temporal aggregation.
  • Spatial utilities — masks, weighted means, and generic regional aggregation.
  • Energy metrics — heating and cooling degree days and related weather-derived measures.

Installation

The package is not yet published on PyPI. During development, install directly from GitHub:

pip install git+https://github.com/jl115-source/wxenergy.git
A standard pip install wxenergy release will be added with v0.1.

Quickstart

The API is intended to stay close to xarray: input objects remain recognizable, coordinates are preserved, and small functions can be composed into larger workflows.

import xarray as xr
import wxenergy as wx

ds = xr.open_dataset("temperature.nc")

ds = wx.standardize(ds)
climo = wx.climatology(ds.t2m, groupby="dayofyear")
anom = wx.anomaly(ds.t2m, climatology=climo)
regional = wx.weighted_mean(ds.t2m, weights=population)

User guide

Standardization

Normalize common weather and climate data conventions before analysis: coordinate names, longitude ranges, time dimensions, units, and metadata.

Climate statistics

Build climatologies and anomalies, calculate percentiles, and aggregate data across standard time scales.

Spatial utilities

Apply masks and weights to gridded weather data without introducing a separate data model.

Energy metrics

Derive general weather metrics used in energy analysis, including heating and cooling degree days.

API reference

The public API will be documented here as the v0.1 package takes shape. The initial modules are planned around:

  • standardize — dataset conventions and units
  • climate — climatologies and anomalies
  • spatial — masks and weighted aggregation
  • energy — degree days and related metrics
