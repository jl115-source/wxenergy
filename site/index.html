wxenergy

Python utilities for working with weather and climate data in energy applications.

Getting started

wxenergy is not yet published on PyPI. The first release will be installable with:

pip install wxenergy

For now, follow development and source code on GitHub.

Features

  • Standardize common xarray coordinates, units and time conventions.
  • Calculate climatologies, anomalies, percentiles and rolling statistics.
  • Compute basic energy-weather quantities such as HDD, CDD and degree hours.
  • Perform spatial and weighted aggregation on gridded weather data.
  • Preserve xarray coordinates and metadata wherever practical.

Scope

The package is intended to handle common, reusable weather-data processing tasks. It is not a forecasting system, power-market model, or trading library.
